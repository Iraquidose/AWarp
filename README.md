# AWarp

Server-side warps, homes and teleports for Minecraft 26.3, on **NeoForge** and **Fabric**. Players don't need to install anything.

- Player warps with visitor counts and a `/warp top` list
- Warp passwords, locking, welcome messages, arrival particles and sounds
- Admin warp tools (`/awarp`)
- Homes, `/back`, `/tpa` and `/spawn`
- Every feature can be switched off in the config
